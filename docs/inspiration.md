# Design inspiration

Used for ideas about the experience, never copied (branding, layout, text or code). Licenses are not verified for the code references, so treat them as ideas only.

## 1. Alibaba.com AI Mode and Accio (main reference)
What we adopt (principles):
- Start from the user's goal, not from menus: a prompt box plus suggested tasks ("Accessories for my phone", "Cheaper alternative", "Bundle for my laptop", "Compare two products").
- Turn a natural-language request into structured results: product cards, comparison tables, bundle cards. Not walls of text.
- Show the work: a visible plan and step status. In our product this comes from real recorded run events, never from fake animations.
- Ask one short clarifying question when information is missing instead of guessing.
- The human takes the final decision. The agent proposes, the merchant approves. Recommendation, approval and execution are separate, visible states.
- Evidence next to every recommendation: stock, compatibility, price limits (merchant side: also margin and rule results).

What we do not adopt: supplier sourcing, RFQs, negotiation, logistics, subscriptions, multi-agent team features.

Source note: only public descriptions were read. The live AI Mode chat could not be opened automatically, so screenshots from the project owner are needed for visual detail.
